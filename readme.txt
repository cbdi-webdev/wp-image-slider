=== WP Image Slider ===
Requires at least: 5.8
Requires PHP: 7.4
Stable tag: 1.3.0

A standalone responsive image slider. No theme, page builder, or JavaScript library dependency.

== Installation ==
Upload wp-image-slider.zip through Plugins > Add New > Upload Plugin and activate WP Image Slider.
Use [wp_image_slider ids="123,456"] or [wp_image_slider] for recent post images.
Configure or check GitHub updates under Tools > WP Image Slider Updates.
On multisite, use Network Admin > Settings > WP Image Slider Updates.
