# Changelog

## 1.3.0 — 2026-10-30

- Rename the plugin and install directory to WP Image Slider / `wp-image-slider`.
- Add `[wp_image_slider]` and `[image_slider]`; retain `[news_slider]` and `[kaia_news_slider]`.
- Remove hardcoded site uploads; allow site defaults through `wp_image_slider_fallback_slides`.
- Add stable GitHub release checks, cached metadata, manual refresh, plugin details, and WordPress update installation.
- Add release metadata compatibility checks and reject incomplete or mismatched releases.
- Add automated checks and tagged releases with an installable ZIP and update manifest.

## 1.2.0 — existing site version

- Custom image sources, control visibility, active dot color, and backward-compatible news shortcodes.
